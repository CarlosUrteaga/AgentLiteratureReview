# AgentOps: Enabling Observability of LLM Agents

**Citation / Link:** arXiv:2411.05285v2  
**Authors:** Liming Dong; Qinghua Lu; Liming Zhu  
**Year:** 2024  

---

## 1. One-Line Contribution
Proposes AgentOps, a DevOps-oriented observability taxonomy and artifact model for tracing LLM agents across their lifecycle to improve safety and accountability.

---

## 2. Problem the Paper Solves
LLM agents are autonomous, non-deterministic, and continuously evolving, yet existing DevOps tools focus on LLM-level metrics and lack visibility into agent-specific artifacts, limiting safety and accountability.

---

## 3. Proposed Solution / Architecture
The paper conducts a systematic mapping study of AgentOps-relevant tools and derives an artifact relationship model for agent traces. It then presents a taxonomy of AgentOps that specifies traceable artifacts and metadata across agent spans (reasoning, plan, workflow, task, tool, evaluation, guardrails, LLM), including inputs/outputs, errors, metrics, and linkages. This taxonomy is intended as a template for building monitoring, logging, and analytics infrastructure to enable observability across the agent lifecycle.

---

## 4. Key Concepts Introduced
- AgentOps observability taxonomy
- Entity-relationship model for agent artifacts and spans
- Traceable metadata for reasoning, planning, workflows, tools, evaluation, and guardrails

---

## 5. Relation to AI Agents / Agent Governance
It defines what should be traced and monitored in agent systems to support safety, accountability, and governance across deployment and evolution.

---

## 6. Strengths
- Systematic mapping study grounding the taxonomy in existing tools
- Concrete artifact and span model that is actionable for observability design

---

## 7. Weaknesses
- No real-world validation of the taxonomy via deployed case studies
- Tool selection may be incomplete due to rapid ecosystem changes

---
