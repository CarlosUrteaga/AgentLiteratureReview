# How AI Impacts Skill Formation

**Citation / Link:** arXiv:2601.20245v1  
**Authors:** Judy Hanwen Shen; Alex Tamkin  
**Year:** 2026  

---

## 1. One-Line Contribution
Reports randomized experiments showing AI assistance in learning a new programming library can reduce conceptual understanding, code reading, and debugging skills without significant average speed gains, and identifies interaction patterns that preserve learning.

---

## 2. Problem the Paper Solves
AI assistance boosts productivity in many settings, but its impact on skill formation and the ability to supervise AI outputs is unclear; the paper tests whether AI help during unfamiliar coding tasks harms learning outcomes.

---

## 3. Proposed Solution / Architecture
The paper designs randomized experiments where participants complete tasks using a new asynchronous Python library (Trio) with or without AI assistance. It evaluates skill formation via quizzes covering conceptual understanding, code reading, and debugging, and analyzes screen recordings to categorize AI interaction into six patterns, identifying engagement-heavy patterns (e.g., conceptual inquiry and explanation-seeking) that better preserve learning outcomes.

---

## 4. Key Concepts Introduced
- AI assistance and skill formation tradeoff in coding tasks
- AI interaction patterns (six categories)
- Learning outcomes in conceptual understanding, code reading, and debugging

---

## 5. Relation to AI Agents / Agent Governance
Highlights risks of cognitive offloading and weakened oversight skills when relying on AI, informing governance and training practices for safe deployment in high-stakes domains.

---

## 6. Strengths
- Randomized experimental design on a concrete, unfamiliar programming library
- Combines quantitative outcomes with qualitative interaction pattern analysis

---

## 7. Weaknesses
- Findings are limited to a specific programming library and task setting
- Uses a particular AI assistant configuration, limiting generalization across tools

---
